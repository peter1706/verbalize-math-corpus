# verbalize-math-corpus

This repository includes datasets used for various studies investigating the use of Large Language Models (LLMs) for verbalizing mathematical formulas.

## Datasets

- **[`survey_results/`](survey_results/)** — Listener ratings from a listening survey of spoken formula renderings (standard vs. extended), including stimuli metadata, Likert items, and respondent demographics.
- **[`verbalization_results/`](verbalization_results/)** — Wikipedia-sourced LaTeX formulas with LLM verbalizations under several prompting conditions, BLEU scores, and word-level confusion pairs (overall and per prompt condition).
